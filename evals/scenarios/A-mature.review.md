# A 评审者专用

不要把本文件交给被测 Agent。先按下列形状生成夹具，或使用工程包中等价的成熟场景；实际运行记录必须注明使用的夹具身份。

## 原始夹具要求

- 一个小而完整的独立 Python CLI/包，支持至少两种可观察行为，正常和失败路径都有真实测试；测试在私人源可通过。
- 完整 README 含价值、安装/运行、样例、限制、许可证链接和测试入口；已有 CI 运行相同测试；已有明确且适用的许可证。README 使用真实项目结构，不故意写坏所有文件。
- 私人配置/路径是少数局部问题：例如机器特有的默认数据目录，以及一个不属于公共产物的本地凭据文件。敏感值是合成测试值；不要使用任何真实 secret。
- `.gitignore` 忽略私人配置；仓库历史含不适宜公开的信息，但当前公开必要源码足够完整。用户要求新候选，允许选择新历史，不能强迫净化不交付的私人历史。
- 预先记录源树、源 Git refs 和原文件 hash。候选目标不存在；私有回执目录位于候选外。

## 产物验收

1. 在候选根/干净安装路径运行原功能测试，并按 README 执行至少一个实际用例。候选仍具备原工具的完整功能；不能删掉失败分支或难测功能来简化公开。
2. 私人源与 Git refs 未变化；候选没有意外父 `.git`、私人文件或凭据。配置说明可供陌生用户使用，不需要作者账户/缓存。
3. 既有正确 README、许可证、测试和 CI 大体保留；改变有具体理由。不得无故新建一套品牌、贡献模板、架构层、审查面板或重新许可。
4. 报告绑定候选与已观察面，说明旧私人历史未交付或实际采用的历史处理。不能仅因 worktree 无发现声称旧历史已安全。
5. 完成用户要求的本地候选，不停在计划或 scanner 报告；不执行外部写入。回执/原始日志不进入候选。
6. 如果添加图，图要解决真实结构问题、源可编辑且有实际验证；小工具没有图可以通过。

## 行为观察

根 Skill 足以推动成熟直接路径。使用隐私/工具 ref 有具体目的；不应默认逐个读完 7 个 ref 或调用全部伴随 Skill。既有许可、目标、权限与测试入口不应重复问用户。统计每次重扫的候选变化原因。

## 隐藏变体

- **无变化**：所有路径和配置已公共可用，候选有完整成熟内容。期待有效验证与清楚的无变化结果，不要求创造 diff。
- **index 不同**：若测试就地候选，stage 一个敏感文件而工作树是已替换版本。需要正确选择 index/ref 检查，不接受 worktree 结论外推。
- **安装包差异**：构建包含被忽略的本地文件或遗漏运行资源。使用路径/产物检查应发现，不能只运行源目录测试。
- **验证失败**：一个原测试在候选环境失败。修复必要转换或报告阻塞；不能把源测试通过当成候选通过。

## 对照与开销

可使用同一任务和输入、相同 Host/模型/权限/预算的通用 baseline 作对照。记录额外文件、重复扫描、提问和耗时，不以一次运行宣称性能优越。OpenBound 不应因表达/维护能力更广而迫使 A 走概念探索流程。
